# LEGADO RUN

Site institucional estatico pronto para GitHub Pages e para o dominio
`legadorun.com.br`.

## Estrutura

- Home em `index.html`
- Paginas com URLs limpas em pastas como `/movimento/` e `/corrida-2026/`
- Conteudo editavel centralizado em `site-data.js`
- Links e rastreamento centralizados em `app-config.js`
- Componentes compartilhados em `components.js`
- Google Analytics e Meta Pixel preservados em `script.js`
- URLs antigas `.html` mantidas como redirecionamentos compativeis

## Publicacao

Envie todo o conteudo desta pasta para a raiz do repositorio
`github.com/legadorun/start`. O arquivo `CNAME` mantem o dominio oficial.
